# BRL Financial Website Clone

This repository contains a clone of the BRL Financial website (www.brlfinancial.com) for development purposes. The original website redirects to fmweb3.com/fmbrl/, which is what has been cloned here.

## Overview

The BRL Financial website is a financial services portal that provides different login options for various user types (Insured, Agent, General Agent, Sales Rep). The website is built using ASP (Active Server Pages) for backend processing and HTML/CSS for frontend presentation.

## Directory Structure

- `fmweb3.com/fmbrl/` - Main website files
- `fmweb3.com/fmbrl/images/` - Image assets
- `fmweb3.com/fmbrl/FMimages/` - Additional image assets
- `fmweb3.com/fmbrl/fonts/` - Custom font files
- `summary.md` - Summary of the website structure and technologies

## Technologies Used

- **Backend**: ASP (Active Server Pages)
- **Frontend**: HTML, CSS, JavaScript
- **Additional Features**:
  - Google Translate API for language translation
  - VeriSign security seal
  - Custom fonts
  - IE compatibility libraries (PIE.htc, csshover.htc)

## Running the Clone Locally

To run this clone locally, you would need:

1. A web server with ASP support (like IIS with Classic ASP enabled)
2. Proper configuration to handle .asp file extensions

For static preview only (without backend functionality):
1. Open any of the HTML files in a web browser

## Backend Functionality Notes

The original website uses ASP for server-side processing. To fully replicate the functionality, you would need to:

1. Set up a database to store user information
2. Implement the authentication logic
3. Create the necessary server-side scripts to handle form submissions

## Limitations of This Clone

This clone includes:
- All frontend assets (HTML, CSS, JavaScript, images, fonts)
- PDF documents and manuals
- Original file structure

This clone does not include:
- Backend database
- Server-side processing logic
- Actual user authentication functionality
